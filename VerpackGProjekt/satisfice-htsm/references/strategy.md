Published: December 2, 2024 by James Bach

The HTSM (v.6.3) is a set of guideword heuristics designed to help you think better about test strategy. It includes four focus areas: test techniques, project elements, product factors, and quality criteria categories. You can use it casually or rigorously. It is pretty generic to any kind of software. I'd encourage you to modify this to fit the context of your own organization.

The 6.3 version has a bunch of changes to emphasize state-based testing and to say more about boundaries.
